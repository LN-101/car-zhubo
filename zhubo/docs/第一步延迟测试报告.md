# 第一步延迟测试报告

测试日期：2026-09-10。范围：命令行文本/文件输入、真实 IndexTTS 2.5 推理、边生成边本机播放。数据来自 `outputs/optimized/metrics.json`。

原始数据副本：[长脚本实测](第一步长脚本实测.json)、[直接文本输入实测](第一步文本输入实测.json)。直接文本输入另测两句新文本：首 PCM 1.045 秒，首设备输出 1.130 秒，音频 5.422 秒，RTF 0.391，应用和设备欠载均为 0。

## 环境与口径

- GPU：NVIDIA GeForce RTX 5070 Ti Laptop GPU，约 12 GB 显存。
- Python 3.11.13，PyTorch 2.8.0+cu128，BF16，单 beam，4 个 CPU 线程。
- 权重：`/home/ln/AI/index-tts/checkpoints`；参考音色：`examples/voice_01.wav`。
- 输出：22050 Hz，单声道，16-bit PCM，本机默认 PortAudio 音频设备。
- 模型加载：11.419 秒；一次预热合成：2.135 秒。模型加载不含此前 Python 导入耗时。
- 首音：请求开始至 PortAudio 回调所报告的首块 DAC 输出时间估计值，不是声学录音测量。请求计时包含打开音频设备。
- 预热输出不播放，也不复用于正式请求。两轮正式请求均重新合成。
- RTF 排除等待播放队列空位的时间。合成完成墙钟时间包含队列等待，因此不能用它代替纯推理耗时。

## 样本与结果

样本：`examples/欧拉5直播脚本.txt`，取自用户提供的车型资料，避开矛盾价格；分成 9 段。第一、第二段较短，后续段在自然标点处合并至最多 32 字符，数字跨边界时保持完整。

在此预热条件、样本与硬件上，两轮均满足 ≤ 3 秒首块输出目标，平均纯推理速度约为播放速度的 2.74–3.17 倍。不能据此宣称任意脚本或冷启动都满足同一指标。

## 优化记录

初版将第二段合并至约 40 字，首段播完时第二段尚未生成，产生 0.882 秒和 0.592 秒缺音。随后限制前两段长度，并缩短后续段，以上最终两轮消除了该样本的缺音。

初版 RTF 含队列等待，不作为最终性能数据；最终 JSON 分别记录每段 `inference_s` 和 `queue_wait_s`。上游终端日志自身的 RTF 仍可能包含生成器暂停时间，应以本模块 JSON 中的统计为准。

## 复现

```bash
cd /home/ln/AI/zhubo
bash run_tts.sh --file examples/欧拉5直播脚本.txt --runs 2 --output outputs/optimized
```

合成带随机性，重复执行会有时长差异。输出 WAV 为生成音频拼接，不包含缺音期间设备补出的静音。保留原始 JSON 供检查。

本次验证不包含主观音色拟人度评分、声学端到端录音测量、动态改稿或长时间稳定性压测。
